本机号码与转发模板

      
国内 SIM 卡通常不向系统提供本机号码。手动填写后，概览和转发出去的短信都会显示对应卡槽的号码；留空则沿用系统读到的号码。

      

        

          
          
        

        
        

          模板占位符：{peer} {body} {code} {device} {tag} {time} {sub} {sim} {slot}。
          模板里没写 {sim} 时自动追加一行「接收号码」，写了则由你决定位置；Webhook JSON 也会带 sim / slot 字段。
        

        
      

    

    

      
异常告警

      
默认只发本地通知。外推通道留空表示不外推；告警不写入短信记录，也不参与重试。
